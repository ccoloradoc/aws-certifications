# AWS Certification Notes

Personal study notes for AWS certifications, organized as one root folder per certification so multiple certs can live side by side in this repo.

## Certifications

- [`saa-c03/`](saa-c03/) — AWS Certified Solutions Architect – Associate (SAA-C03)

## How to use this repo

Each certification folder is organized by AWS service domain (compute, networking, storage, databases, etc.), mirroring how AWS documents its own services. Every topic file starts seeded with condensed facts from a cheat sheet as a base, plus a `## Notes` section for you to expand with your own understanding, exam gotchas, and links as you study.

When starting a new certification, copy the folder layout pattern from `saa-c03/` (numbered domain folders + `00-exam-strategy.md` + `README.md`) and adjust the domains to match that exam's scope.
