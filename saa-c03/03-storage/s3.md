# S3 (Simple Storage Service)

- Durability: 99.999999999% (11 nines)
- Best practices: enable versioning and MFA Delete

## Lifecycle Actions

- **Transition actions** — move objects between storage classes
- **Expiration actions** — delete objects
- 30-day minimum before a lifecycle policy takes effect

## Storage Tiers

- **Intelligent Tiering** — automatic cost optimization based on access patterns
- **Standard-IA** — infrequent access, replicated across multiple AZs
- **One Zone-IA** — infrequent access, single AZ (cheaper, less durable)

## Access Control

- **Pre-signed URLs** for temporary, time-limited object access
- Prefer IAM policies over bucket ACLs
- **Multi-part upload** for large files

## Limitations

- API access requires auth; static website hosting doesn't support HTTPS natively
- Use CloudFront + S3 for HTTPS-enabled static hosting (see [content-delivery.md](../02-networking/content-delivery.md))
