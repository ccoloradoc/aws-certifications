# AWS Overview

Introductory, non-technical context from the very start of the course (pages 1-30) — the kind of thing every later topic assumes you already know. This content got summarized in chat early in the note-taking process but never made it into a persistent file until this pass.

## What is AWS?

- AWS (Amazon Web Services) is a cloud provider — it gives you servers and services you can use on demand and scale easily
- Has reshaped how IT is done; powers some of the biggest sites in the world (Amazon.com, Netflix, and many more)

## AWS scale (facts as presented in the course, ~2023-2024)

- ~$90 billion in annual revenue (2023)
- ~31% of the cloud market in Q1 2024 (Microsoft Azure 2nd at ~25%)
- Positioned as the leader in Gartner's Magic Quadrant for Strategic Cloud Platform Services for 13 consecutive years
- Over 1,000,000 active users

## Common use cases

- Enterprise IT
- Backup & storage
- Big data analytics
- Website hosting
- Mobile & social apps
- Gaming
