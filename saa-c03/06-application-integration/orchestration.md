# Orchestration

## AWS Step Functions

- Build a serverless **visual workflow** (state machine) to orchestrate Lambda functions and other services
- Features: sequences, parallel branches, conditions, timeouts, error handling, and the possibility of a **human approval** step
- Can integrate with EC2, ECS, on-premises servers, API Gateway, SQS queues, and more
- Use cases: order fulfillment, data processing pipelines, web applications — any multi-step workflow needing visibility and retries

## AWS Simple Workflow Service (SWF)

- Older task execution/coordination service, largely superseded by Step Functions — not covered in the slide deck
